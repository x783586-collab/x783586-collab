LINE

两种玩法可同时用：官方账号走 Token + Secret；个人账号用手机通知转发，自定一个转发口令。

LN玩法 A · 官方 Messaging API 未配置

如何创建官方账号并拿到这两个值：打开 LINE 配置向导

玩法 B · 手机通知转发

没有机器人、只有自己账号时用这个：手机收到 LINE 通知后转发给 Hub。具体设置见刚才的向导「玩法 B」部分。

关于
