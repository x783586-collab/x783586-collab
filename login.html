连接你的 Telegram

连接后，这个挂件会在屏幕边缘显示你的新消息。所有数据只留在本机。

? 不知道怎么获取？点开看 5 步说明 ▸
  1. 打开 my.telegram.org，填你的手机号登录。
    验证码不发短信，会发到你 Telegram App 里。
  2. 登录后点 API development tools。
  3. 表单随便填：App title 写 hud，Short name 写 hud，Platform 选 Desktop，网址和描述留空。
  4. 点 Create application 提交。
  5. 页面上会出现 App api_id（一串数字）和 App api_hash（32 位字母数字），照抄到下面两个框里。
网站打不开是网络问题，先开代理再访问。一个手机号只能有一个应用，如果你以前建过，页面会直接显示原来那组，不用重新建。
网络设置（连不上时再填）
填写你账号的 API 凭证，等同于这台电脑登录了你的 Telegram。凭证与登录态只保存在本机配置文件中，不会上传到任何服务器。
验证码会发到你 Telegram 的任意一台已登录设备上。
