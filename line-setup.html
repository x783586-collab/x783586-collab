接入 LINE

选一种方式，跟着步骤点下去，每一步都能当场验证。全程约 5–10 分钟。

玩法 A官方账号方式 · 能回复 用你自己的 LINE 账号免费创建一个官方账号（不用买认证号、不用额外手机号）。能收发给它的私聊和所在群的消息，挂件里可以直接回复。需要 LINE 账号，无需 Android。
玩法 B手机通知转发 · 不建账号 不建任何账号。用 Android 手机的 MacroDroid 监听 LINE 通知转发过来，能收到手机上真实的全部 LINE 消息（私聊 / 群 / 频道），但挂件里不能回复。仅支持 Android。
两种方式共用同一个「公网中转」（部署到 Cloudflare，免费），只做一次。以后想换玩法随时回来改。
1创建免费官方账号，拿到两个凭证
?怎么创建？点开看 5 步说明▸
  1. 打开 manager.line.biz，用你的 LINE 账号或邮箱注册 Business ID 并登录（就是手机上那个 LINE）。
  2. 按引导填写资料创建 LINE 官方账号，名字随便，如 我的通知。免费计划即可，不用认证、不用绑卡。
  3. 在这个官方账号里找到 Messaging API → 点开通，这一步会同时创建 Messaging API 频道。
  4. 用同一个账号登录 developers.line.biz/console → 选刚建好的频道 → Messaging API 标签页底部 Channel access token 点 Issue，复制那串长 Token。
  5. 切到 Basic settings 标签页复制 Channel secret（32 位），下面要用。
注意：2024-09-04 起已不能在 developers.line.biz 里直接新建频道，必须先到 manager.line.biz 建官方账号再开通——老教程里的入口已经失效。官方账号不是买广告认证的那种，个人免费版就能用。
Token 用来收消息和回复；Secret 只用于中转校验消息来自 LINE，都不会上传到任何第三方。
2部署公网中转（一次性，免费）
?为什么需要中转？怎么部署？▸
  1. LINE 只支持 webhook 推送，家庭电脑没有公网地址，需要一个中转。代码就在下面，部署到 Cloudflare Workers（免费）。
  2. 打开 dash.cloudflare.com 注册/登录 → 左侧 Workers & Pages → Create Worker → 名字随意（如 line-hud）→ Deploy。
  3. 点 Edit code，删掉示例代码，用下面的「复制中转代码」粘贴（口令和 Secret 已经自动填好）→ 右上 Deploy。
  4. 给 Worker 绑数据库：Worker 页面 → Settings → Bindings → 添加 KV Namespace，变量名填 LH_KV（Namespace 新建一个即可）→ Deploy 生效。
  5. 地址就是 https://你的名字.你的子域.workers.dev，填到下面的框里。
复制出来的代码里，中转口令已经替你随机生成并填进下面的输入框，两边保持一致即可，不用记。

3接通 LINE，开始收消息
然后还剩一个开关只能去 LINE 控制台手动打开：
!去控制台打开「Use webhook」（30 秒）▸
  1. 回到 developers.line.biz → 你的官方账号 → Messaging API 标签页。
  2. 找到 Use webhook 开关，打开（自动配置按钮已帮你填好 URL，点 Webhook URL 下面的 Verify 应显示 Success）。
  3. 建议顺手到 LINE Official Account Manager 的「回复设置」里关掉自动回复，避免默认文案干扰。
保存后：手机 LINE 给你的官方账号发条消息，挂件右下角就会冒出来。以后改配置在挂件设置 → 消息来源 → LINE。
1部署公网中转（一次性，免费）
?部署步骤▸
  1. 打开 dash.cloudflare.com 注册/登录 → Workers & Pages → Create Worker → Deploy。
  2. 点 Edit code，删掉示例，用「复制中转代码」粘贴 → Deploy。
  3. Worker 页面 → Settings → Bindings → 添加 KV Namespace：变量名 LH_KV，Namespace 新建即可。
  4. 地址 https://你的名字.你的子域.workers.dev 填到下面，点「测试中转」。
这个 Worker 同时也是手机转发消息的接收点。Secret 在玩法 B 里只是占位（不用验签），复制代码时已自动随机填好。

2手机装 MacroDroid，转发 LINE 通知
?手机上的操作（一次配置，永久生效）▸
  1. Android 手机装 MacroDroid（Play 商店或官网，免费够用），首次启动允许「通知访问权限」。
  2. 添加宏 + → 触发器选 通知 → 收到通知 → 应用选 LINE。
  3. 动作选 HTTP 请求 → 方法 POST → URL 点下面的复制按钮粘贴（已带你的地址和口令）。
  4. 请求体（Body / Payload）也用下面的复制按钮粘贴，{title} 是发信人名、{message} 是内容，MacroDroid 会自动替换。
  5. 保存宏 → 用另一台手机/朋友给这台手机的 LINE 发条消息测试。
要求手机保持 MacroDroid 在后台运行（加白名单省电策略）。iOS 读不到通知内容，所以玩法 B 仅支持 Android。
保存后挂件立刻开始轮询中转（每 6 秒）。消息按发信人自动分成不同的会话。
配置完成

LINE 已接入，挂件开始接收消息。可以关掉这个窗口了。
